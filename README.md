# MEO
## Installation
0. Activate shell and install requirement dependencies (DEV only) 
```shell
python3 -m venv venv
source ./venv/bin/activate # linux only
.\venv\Scripts\activate.ps1 # Windows only
pip3 install -r requirements.txt
```
1. Edit `main.py` and run script
```shell
python3 main.py
```
